# homedia-web

Homedia 家庭媒体库，支持视频、音频、图片

前端：本项目

后端：https://github.com/clfundev/homedia-server.git



## 快速开始

1. 项目根目录创建 `.env` 文件，指向后端服务地址

   ```
   VITE_BASE_URL=http://localhost:9090
   VITE_WS_BASE_URL=ws://localhost:9090
   ```

2. 启动开发服务器

   ```sh
   npm install
   npm run dev
   ```

3. 访问 http://localhost:5173
